# Проверки и ограничения миграционного проекта

## Подтверждено в среде подготовки

- `python -m unittest discover -s tests -v`: 3/3 теста успешно.
- `kotlinc` скомпилировал независимый `QuranCatalog.kt`; инварианты 114 сур, 604 страницы, 6236 аятов, 30 джузов, 60 хизбов, 7 манзилей проверены через Kotlin.
- Четыре исходных Android XML-файла успешно разобраны XML-парсером.
- Для декодера картинок исправлена ошибка, при которой режим `inJustDecodeBounds` ошибочно считался отсутствием изображения.
- Файлы проекта, скрипт импорта исходных временных отметок и загрузчик ZIP-архивов подготовлены.

## Не проверено или отсутствует

- **Android APK/AAB не собран**: в этой среде нет Android SDK, Gradle-зависимостей и доступа к сети для их загрузки.
- **Не гарантируется функциональная эквивалентность всей Java-версии**: не весь оригинальный проект был получен.
- **Не включены** исходные фотографии 604 страниц, 4 новых архива, оригинальный хадр MP3 и JSON тафсира.
- **Нет заполненного `legacy_timings.json`**: вымышленные тайминги недопустимы; для точного переноса запускается `tools/sync_legacy.py` с реальным последним коммитом.
- **Не проведена сетевая верификация 43 репозиториев чтецов и всех MP3-путей**. Проект извлекает публичный список из API GitHub при работе приложения.
- Не проведены испытания фонового воспроизведения, диспетчера аудио, импорта страниц, публикационной подписи и миграции на реальном Samsung SM-A566E.

**Статус: технический проект для дальнейшей миграции, не готовый релиз.** Не публикуйте и не устанавливайте поверх действующей версии, не выполнив проверки.
