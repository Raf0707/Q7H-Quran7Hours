# Quran7Hours — Kotlin + Jetpack Compose (миграционный проект)

## Реальный статус

Это **незавершённый миграционный проект**, а не готовый к публикации APK/AAB и не подтверждённая полная 1:1-замена Java-приложения. Приложение и интеграционные части написаны на Kotlin/Compose; базовая структура проекта и алгоритмы переноса подготовлены, но доступ к исходному Git-репозиторию из среды создания архива не позволил загрузить все файлы и проверить конечную Android-сборку на устройстве.

Блокеры для точной миграции: исходный Java-репозиторий целиком и четыре ZIP-архива по 604 страницы не были доступны как локальные файлы; аудио «Коран за 7 часов» и JSON тафсира сюда **не включены**. Без них приложение не сможет показывать все страницы/тафсир или воспроизводить исходную полную запись. Корректность HTTPS-аудио всех 43 репозиториев по одному только имени пути также не подтверждена.

## Что уже реализовано в коде

- Сохранён **`applicationId = raf.console.quran7hours`**, подпись релиза должна остаться от прежней версии. Имя — «Коран за 7 часов». `versionCode = 6` (в оригинальном Java-репозитории `5`).
- Compose: основной экран — фиксированная картинка страницы с жестовым перелистыванием, компактная верхняя панель, нижние действия, боковой каталог.
- 5 каталогов: суры, страницы, джузы, хизбы, манзили, выделение и переход, автопрокрутка каталога к текущему месту. Исправлены две явные ошибки в старом массиве начала сур (568 вместо 558, 605 за пределами 604).
- 8 цветовых акцентов, светлая/тёмная/системная темы, повышенный контраст, таджвид включён/выключен.
- Импорт четырёх отдельных ZIP по 604 страниц на устройство без расширения APK, защита от Zip Slip, проверка количества страниц и ограничение распаковки.
- Тафсир из исходного постраничного JSON, с отдельными блоками цитат и арабского текста.
- Задел для 43 потоковых q7h_-чтецов через GitHub API (только названия с нижним регистром `q7h_`, `q7h_nabil_rifai` исключён), прямые HTTPS-ссылки на MP3. Аудиофайлы не записываются в кэш или память приложения как отдельные файлы. Обратите внимание: сетевой HTTP-буфер проигрывателя существует в оперативной памяти по определению.
- Media3 MediaSessionService с фоновым воспроизведением, паузой, перемоткой и повтором одного трека.
- Поддержка фонового расчёта таймингов/выделения, полная строка «Сура / Страница / Джуз / Хизб / Манзиль» под плеером, переключение цвета активных элементов.
- Закладки, восстановление последней страницы из `LastPagePrefs` предыдущей версии, настройки в SharedPreferences.

## Сначала перенесите реальные данные

Откройте терминал в корне этого проекта. Нужен Python 3.10+, Git и интернет.

```bash
python tools/sync_legacy.py
```

Скрипт клонирует `https://github.com/Raf0707/Q7H_Old_Java_Version` и читает **точные** `suraTimingsMs` (114) и `pageTimingsMs` (604) из `MainActivity.java`. Сохраняет миллисекунды и оригинальные пометки `ГОТОВО` / `ЗАМЕНИТЬ` в `app/src/main/assets/legacy_timings.json`, записывает SHA коммита и импортирует директории тафсира. Не меняйте `pageTimingsMs` вручную без сверки с оригиналом.

Если исходник уже скачан:

```bash
python tools/sync_legacy.py --source "C:\\Projects\\Q7H_Old_Java_Version"
```

Если скачан оригинальный ZIP:

```bash
python tools/sync_legacy.py --source-zip "C:\\Downloads\\Q7H_Old_Java_Version-master.zip"
```

Для использования двух исходных наборов рисунков при сборке добавьте `--copy-original-images` (это существенно увеличит размер APK). **Рекомендуется** использовать функцию «Настройки → Архивы мусхафа» в приложении и импортировать четыре ZIP на телефоне по очереди. Если нужен предзагруженный контент, скрипт принимает:

```bash
python tools/sync_legacy.py --source "..." \
  --light-tajweed-zip "light_tajweed.zip" \
  --light-plain-zip "light_plain.zip" \
  --dark-tajweed-zip "dark_tajweed.zip" \
  --dark-plain-zip "dark_plain.zip"
```

Каждый ZIP должен иметь страницы с числами `001`…`604` и расширениями `jpg`, `jpeg`, `png` или `webp` (вложенные каталоги допустимы). Важно: сборка с четырьмя наборами может быть очень тяжёлой; для лёгкого приложения импортируйте их после установки.

Оригинальную аудиозапись `quran_7_hours.mp3` загрузите в `app/src/main/assets/quran/quran_7_hours.mp3` или выберите уже имеющийся MP3 через вкладку «Аудио → Коран за 7 часов → Выбрать MP3». Не храните большую запись в APK, если нужен компактный установочный файл.

## Сборка

1. Android Studio с Android SDK 35, JDK **17 или 21** в `Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK`. Не используйте Java 25 с Gradle 8.14.3.
2. Откройте корень архива. Дождитесь загрузки зависимостей Google Maven и Gradle.
3. Windows: `gradlew.bat :app:assembleDebug`. Linux/macOS: `./gradlew :app:assembleDebug`.
4. Установочный debug APK появится в `app/build/outputs/apk/debug/` только после успешной сборки на вашей машине. Для обновления приложения из Google Play нужен **ваш прежний signing key**, а также полноценные smoke-тесты.

`gradle/wrapper/gradle-wrapper.jar` — компактный локально скомпилированный **bootstrap**, поскольку стандартный wrapper нельзя было скачать. Он загружает официальный Gradle 8.14.3 и проверяет SHA-256 по официальному файлу. После первого Gradle Sync желательно заменить bootstrap стандартным wrapper: `gradlew.bat wrapper --gradle-version=8.14.3`.

## Критически важные проверки перед публикацией

- [ ] Успешное `assembleDebug` и `assembleRelease`; тестирование на Samsung SM-A566E.
- [ ] Реальные изображения всех 604 страниц в четырёх режимах (2 темы × таджвид).
- [ ] Точное содержимое тафсира, цитаты и сноски; сверка русского и арабского текста.
- [ ] 43 реальных публичных q7h_ аудиорепозитория, правильность путей GitHub и доступность 6236 MP3 у каждого чтеца (нужна полноценная сетевая проверка; предполагать без проверки нельзя).
- [ ] Последний SHA оригинального проекта и 604 числовых тайминга страниц; не допускать подстановки фиктивных чисел.
- [ ] Джузы, хизбы, манзили в текущем проекте получают **приблизительный тайминг начала страницы** и пометку «ИЗМЕНИТЬ»: каждый требует ручной сверки.
- [ ] Сквозная функциональная проверка оригинальных режимов. Некоторые разделы старой Java-версии (жесты, словарь, экран информации, часть специфических настроек) в Compose **пока не перенесены 1:1**.
- [ ] Система разрешений Android 13+, media notification, смена чтеца и воспроизведение при заблокированном экране.
- [ ] Версия, Play Console target API, подпись, миграция сохранённых данных на копии настоящего приложения.

## Автоматические проверки кода

```bash
python -m unittest discover -s tests -v
```

Скрипт-парсер тестируется на непрерывность 604/114 таймингов и корректность статусов. Обычная проверка `kotlinc` проходит для независимой модели `QuranCatalog`. Android-сборка **не выполнялась** в среде создания архива из-за отсутствующего SDK/зависимостей.

## Права / приватность

Исходные арабские тексты и изображения следует сверять с вашими лицензионными источниками. Аудио в q7h_-репозиториях может иметь ограничения распространения. Приложение не собирает пользовательские данные и не встраивает сетевую рекламу/аналитику; GitHub API используется только для получения списка аудиорепозиториев.
